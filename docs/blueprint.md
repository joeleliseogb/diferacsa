# **App Name**: González Manager

## Core Features:

- Sales and POS: Sales management with point of sale (POS) interface supporting tickets, invoices, returns.
- Inventory Management: Inventory management, tracking stock by warehouse and generating stock alerts. Includes inventory counts.
- Customer Management: Customer management (CRM) with customer profiles, purchase history and segmentation.
- Route management: Route management functionality.
- Smart product recommender: Use AI to help the user choose products based on historic data as a helpful tool
- Reporting: Reporting and statistics dashboard.

## Style Guidelines:

- Primary color: HSL(30, 70%, 50%) - RGB(229, 165, 25) for a warm, reliable feeling. A slightly toned-down shade of golden yellow to inspire confidence and highlight information.
- Background color: HSL(30, 20%, 95%) - RGB(250, 247, 240) for a clean, soft backdrop that complements the primary color.
- Accent color: HSL(60, 80%, 40%) - RGB(184, 204, 25) provides a clear contrast to highlight key actions.
- Font pairing: 'Poppins' (sans-serif) for headings, offering a clean and modern feel, paired with 'PT Sans' (sans-serif) for body text, ensuring readability and balance.
- Icons: Simple, geometric icons to match the modern sans-serif fonts. Consistent stroke weight for a cohesive look.
- Clean and structured layout with ample whitespace for clarity.
- Subtle transitions and animations to provide feedback on interactions without being distracting.
